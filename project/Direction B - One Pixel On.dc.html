Direction B

One pixel on

A system is either running or it isn’t. We build the ones that stay on.

The pixel reduced to its essence: a single point of light that means live. There is only ever one on a screen. It never decorates, it marks where the system is running, where you are, or what happens next.
01 Central idea
{{ conceptPixel }}
A field of dark. One point of light. Everything else is off.

Built by operators. PixelMetrics doesn’t hand over a project and leave, “we build it, we run it.” The lit pixel is the running light on a machine someone is responsible for. It’s a promise, not an ornament.

Restraint as proof. Anyone can fill a screen. Owning a whole identity with one square of colour is a demonstration of the discipline founders are paying for: remove everything that isn’t doing work.
